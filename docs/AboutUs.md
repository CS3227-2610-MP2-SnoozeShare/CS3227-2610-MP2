# About Us

SnoozeShare is a CS3227 Mini Project 2 application for short-term property
rentals. It supports Guests, Hosts, and Support Agents through role-specific
workflows for discovering properties, managing bookings, and resolving issues.

This page is reserved for the team introduction, project motivation, and
acknowledgements.
